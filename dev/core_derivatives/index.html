Derivatives

Tradeable instruments — Buy/Sell for the underlying, plus LongCall/LongPut/ ShortCall/ShortPut — dispatched through a common payoff interface.

Orcus.Derivative — Type
Derivative

Abstract type for all derivatives.

source
Orcus.InstrumentKey — Type
instrument_key(D::Derivative)

Hashable identifier under which positions net. Two fills net into the same position iff their keys are equal: same ticker, same derivative type, same strike (options) and same expiry (short options). Buy and Sell on one ticker are distinct keys and do not net against each other.

source
Orcus.payoff — Function
payoff(D::Derivative, x)

The derivative's payoff structure evaluated at underlying value x. Dispatched on the concrete type (no boxed Function field), so value(D) is type-stable and inlinable.

Orcus.print_props — Method
print_props(D::Derivative)

Print all the current properties of the input derivative.

Orcus.@generate_derivative — Macro
@generate_derivative(Name::Symbol, structure::Expr, price_func::Expr)

Macro to generate a new derivative type.

Examples

@generate_derivative NewBuy x->x (val,premium)->val+premium

x = asset()
name(NewBuy(x,10))

# output

"NewBuy"
